🔑 КРИТИЧЕСКИЕ ПЕРЕМЕННЫЕ .ENV

TOKEN                 - Telegram Bot API токен (ОБЯЗАТЕЛЬНО)
ADMIN_ID             - ID администратора (ОБЯЗАТЕЛЬНО)
CHAT_ID              - ID канала уведомлений (ОБЯЗАТЕЛЬНО)
ORDERS_CHAT_ID       - ID канала заказов (ОБЯЗАТЕЛЬНО)
USERNAME             - Юзернейм бота (ОБЯЗАТЕЛЬНО)
SUPPORT              - Юзернейм поддержки (ОБЯЗАТЕЛЬНО)

DB_HOST              - Хост БД (localhost или db для Docker)
DB_USER              - Пользователь БД
DB_PASSWORD          - Пароль БД
DB_NAME              - Название БД

FLASK_ENV            - production или development
FLASK_DEBUG          - 0 для production
